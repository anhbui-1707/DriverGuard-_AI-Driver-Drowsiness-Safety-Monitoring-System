# MediaPipe model

`face_landmarker.task` is Google's pre-trained MediaPipe Face Landmarker model,
float16, version 1. It detects landmarks; it is not a trained DriverGuard
drowsiness classifier. DriverGuard's geometric analysis comes in later phases.

Source: https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/1/face_landmarker.task

Documentation: https://ai.google.dev/edge/mediapipe/solutions/vision/face_landmarker

Downloaded by `scripts/download_model.py`; bundled for offline startup.
